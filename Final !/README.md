![English Version : This project is a small web application called Add Name that allows managing a list of student names in a classroom. The interface is built with HTML, styled using CSS, and made interactive with JavaScript. The page displays a title decorated with a sun-shaped emphasis effect, followed by a form consisting of an input field and a button. The user can enter a name, which is automatically formatted so that each word begins with a capital letter and the rest is in lowercase. The input field is validated to accept only letters and spaces, and it is required to submit the form. When a name is added, the script checks that it does not already exist in the list to avoid duplicates. Each name is displayed inside a card containing the text and a delete button < X > that allows removing the entry. The cards are animated with a smooth transition that makes them slide in from the left, and they are automatically sorted alphabetically after each addition. The user is also directly redirected to the newly added card. The list is contained within a scrollable area with a customized scrollbar, and it adapts to different screen sizes thanks to responsive CSS rules. The button and input field feature visual effects on hover and focus, enhancing the user experience. In summary, this project demonstrates the creation of a simple and elegant interface to dynamically manage a list of names, with validation, formatting, deletion, automatic sorting, animations, and smooth scrolling.
